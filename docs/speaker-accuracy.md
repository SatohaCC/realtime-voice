# 声紋登録・短発話照合

## 登録

登録画面では、表示された異なる文章を3回読み上げる。ブラウザで有効音声を概算し、各回で約3秒分集まると次へ進む（各回最大10秒）。進捗は経過時間でなく有効音声の量を表示する。登録時も2マイク収音時と同じく自動音量補正を無効にする。

各録音のフレーム数を `sample_frames` クエリの繰り返しで `/api/speakers/enroll` に渡す。省略時は従来の単一録音として扱う。本文はモノラルPCM16の連結で、既定のサイズ上限は16kHz・30秒分（960,000バイト）。既存の `SPEAKER_ENROLLMENT_MAX_BYTES` 設定がある場合はそちらを優先する。

サーバーは20ms単位で音量・音割れを計測し、各回で有効音声が既定2.5秒以上あることを確認する。低音量部分を細切れに削除・連結すると声紋照合を悪化させるため、抽出器には無音や子音も含む連続した元波形を渡す。録音中のクリッピング率が1%以上なら再録音を求める。抽出した各ベクトルを正規化し、全ペアのコサイン類似度が `SPEAKER_PHARMACIST_HIGH_THRESHOLD` 以上の場合のみ平均・再正規化する。

保存形式は従来と同じだが、加工前提が変わるため既定の識別子を `3dspeaker_campplus_zh_en_16k_contiguous_v2` に更新した。旧識別子の声紋は再登録が必要。`SPEAKER_MODEL_ID` を独自設定している場合も、加工条件を変更したら識別子を更新する。

## 照合と再判定

声紋抽出前に登録時と同じ品質検査を適用し、有効音声が `SPEAKER_MIN_EMBED_SECONDS` 未満、音割れ率が1%以上、履歴不足の場合は抽出しない。声紋登録済みなのに抽出できない場合やベクトルの次元が合わない場合は、マイク番号から話者を推測せず話者不明とする。途中結果や声紋登録の拒否後も、声紋で未確認の話者名を表示しない。

患者の一時重心を初期化できるのは、薬剤師に不一致・患者マイク優位・既定1.2秒以上の区間に限る。初期化後は既存の患者声紋に一致する場合だけ更新し、不一致音声で上書きしない。

声紋登録時の短発話は音量だけで話者を確定せず、話者不明として保持する。同一マイクが優位な隣接短発話について、間隔350ms以内・最大4件の直前候補を蓄積する。別チャンネルの確定発話の割り込み、重畳、長い空白、音量の拮抗があれば蓄積しない。蓄積音声の声紋照合で話者が判明した場合のみ、候補を `refined` として訂正し、既存のイベント・SOAP再評価経路に流す。ストリームを跨いで蓄積しない。

## 評価上の限界

品質検査は音量とクリッピングによる計測であり、雑音と声を識別する学習済みVADや同時発話検出ではない。連続した短発話が同一人物であることも保証できない。単独の短い相槌や同音量の区間は話者不明のまま残る場合がある。

合成PCM・スタブモデルによるテストは処理の正しさを確認するもので、認識精度の改善を証明しない。実際の日本語・2マイク音声で、登録用・閾値調整用・最終評価用を分離し、誤割当率・話者不明率・短返答保持率を測定する。閾値やモデルの変更は、この比較結果に基づいて行う。

## 音声加工の回帰検証

ローカル配置済みのCAM++モデルと中国語サンプル（`leijun` / `fangjun` の登録用・別録音）を使用した小規模確認では、同じ登録ベクトルに対する本人の先頭3秒の類似度が、元波形では0.593、低音量区間を除去・連結すると0.345となった（判定閾値0.50）。加工をやめ、登録・照合とも連続波形で揃えた場合は本人0.598、別人0.328で、それぞれ薬剤師・患者と判定できた。

`test_speaker_model_regression.py` はこの独立録音を用いる実モデルの回帰テスト。モデルやサンプルがない環境では明示的にskipする。この結果は日本語や実際の2マイク会話の精度を保証しない。
